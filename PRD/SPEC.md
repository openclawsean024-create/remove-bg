## §0 評估結論

| 項目 | 結論 |
|---|---|
| 現況完成度 | **15 / 100**。有登入／註冊 API、定價頁、歷史頁與 Supabase schema，但**核心去背沒有真的運作**：未設 token 時直接回傳原圖；有 token 時呼叫 Replicate 後不輪詢結果，`prediction.output` 幾乎必為空，仍回傳原圖。背景換色只是在 URL 加 `?bg=` 參數。無上傳（只能貼圖片 URL）、無扣點、無金流。 |
| 獲利潛力 | **低**。去背已是商品化功能：remove.bg、Canva、Adobe Express、Photoroom 等工具，以及作業系統內建的主體去背皆可免費或低價完成（各家價格與方案待確認）。價格戰下單張毛利薄，且自架模型需 GPU 成本。 |
| 目標客群（假設） | 台灣蝦皮賣家、小型餐飲與補習班需要產品照／文宣去背者。付費意願未經訪談驗證。 |
| 獲利模式（假設） | 免費增值（免費試用 + 點數包／月訂閱）。 |
| 主要風險 | ① **模型授權**：程式註解寫使用 RMBG-1.4（BRIA）；依 Hugging Face 模型卡記載，RMBG-1.4 為 BRIA 自訂的**非商用**授權，商用須另與 BRIA 簽約（本次未連網重新查證，**待法務確認**）。在未取得商用授權前收費使用即有侵權風險。舊 SPEC 寫 rembg／U2-Net，與程式不一致。② **不實廣告**：repo 描述寫「台灣最便宜」、首頁與定價頁寫「比 Remove.bg 便宜 31%」，repo 內**沒有任何比價依據或計算**，對外使用可能構成不實廣告（公平交易法第 21 條，待法務確認）。③ 安全：登入 cookie 直接存使用者 UUID、去背 API 無驗證可被濫用耗用付費 API、RLS 讓任何人讀取所有匿名上傳紀錄。④ 競品強且免費替代多。 |
| 建議 | **封存**。核心功能未實作、市場已商品化、模型授權與比價宣稱都有法律風險；投入補齊的成本高於可預期收益。若 Sean 仍需要去背能力，建議做成其他產品的**內建功能**（例如梗圖產生器的「上傳自己的照片並去背」），使用確認可商用的模型，而不是獨立收費 SaaS。 |
| 與其他產品重疊 | 本批 `tw-meme-generator`（台灣梗圖產生器）若開放使用者上傳圖片，可重用去背能力。第一批 10 個產品清單本 brief 未提供，重疊情形待確認。 |

> 本 repo 不做封存、刪除或改名；是否封存由 Sean 決定。

## 1. 問題（假設）

台灣小商家需要產品照、菜單、LINE 貼圖素材去背，並輸出台灣常用尺寸；國際工具介面與計價以外幣為主。此問題是否足以支撐付費，**未經驗證**。

| 角色 | 描述 | 驗證狀態 |
|---|---|---|
| 蝦皮／電商賣家 | 需白底產品照 | 未驗證 |
| 小型餐飲、補習班 | 菜單、DM 去背 | 未驗證 |

| 競品 | 類型 | 備註 |

| remove.bg | 去背 SaaS | 價格待確認；程式宣稱「便宜 31%」無依據 |
| Canva、Adobe Express | 設計工具內建去背 | 方案與限制待確認 |
| Photoroom | 電商產品照 App | 待確認 |

差異化假設（在地尺寸、NT$ 計價、繁中介面）皆未驗證，且容易被競品複製。

狀態：已實作／部分／未實作（皆在 `remove-bg`）。

| FR | 需求 | 優先 | 狀態 | 說明（以程式為準） |
|---|---|---|---|---|

## 5. 非功能需求（若重啟）

- 單張處理 p95 < 8 秒；上傳限 10 MB、JPG／PNG／WebP。
- 上傳圖片移除 EXIF（含 GPS）；原圖與結果 24 小時內刪除（期限待確認）。
- 付費模型呼叫需有每帳號與每 IP 的速率限制。

## 6. 資料與個資處理

| 資料 | 等級 | 現況 | 應有處理 |
|---|---|---|---|
| Email、密碼雜湊 | 個資 | 存 `users` 表 | 改用單一驗證系統；錯誤訊息不回傳資料庫原文 |
| 使用者上傳圖片 | 可能含人臉與個資 | 只存外部 URL | 移除 EXIF、限期刪除、不得公開讀取 |
| 匿名處理紀錄 | — | RLS `images_anon_read` 允許任何人讀取所有 `user_id IS NULL` 的紀錄 | 改為只能以處理 ID + 簽章讀取 |

## 7. 法規與風險

| 風險 | 說明 | 對策 |
|---|---|---|
| 模型授權 | RMBG-1.4 非商用授權（待法務確認）；Replicate 版本 hash 是否確為 RMBG-1.4 也待確認 | 收費前改用確認可商用的模型（候選：U2-Net／rembg、BiRefNet 等，各自授權皆**待確認**），或取得 BRIA 商用授權 |
| 不實廣告 | 「台灣最便宜」「比 Remove.bg 便宜 31%」無依據 | 移除或附可查證的比價表與日期 |
| 使用者上傳內容 | 可能含他人肖像或侵權素材 | 服務條款要求使用者擁有權利；提供檢舉下架 |
| 付費 API 濫用 | `/api/remove` 無驗證 | 驗證 + 扣點 + 速率限制 |
| 競品 | 免費替代多 | 封存或改為其他產品的內建功能 |
